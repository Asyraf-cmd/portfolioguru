PANDUAN PEMASANGAN PWA
e-Portfolio Profesionalisme Guru — Fasa 2

1. Buat sandaran penuh melalui fungsi eksport JSON dalam aplikasi sebelum menggantikan fail.
2. Ekstrak ZIP ini.
3. Muat naik SEMUA kandungan ZIP (index.html, manifest.webmanifest, sw.js dan folder icons)
   ke root repositori GitHub Pages yang sama. Jangan letakkan semuanya dalam subfolder tambahan.
4. Commit dan push perubahan. Pastikan Settings > Pages menerbitkan branch/folder yang betul.
5. Buka laman GitHub Pages menggunakan HTTPS.
6. Android: Chrome > menu > Install app / Add to Home screen.
   iPhone/iPad: Safari > Share > Add to Home Screen.

PENTING TENTANG DATA
- Aplikasi ini kekal local-first; tiada penyegerakan awan antara komputer dan telefon.
- Rekod localStorage dan IndexedDB terikat pada pelayar/peranti serta origin/domain laman.
- Kekalkan alamat laman yang sama. Pertukaran domain boleh menyebabkan rekod lama tidak kelihatan.
- Service worker menyimpan rangka aplikasi untuk pembukaan luar talian; ia bukan sandaran rekod.
- Jangan padam data laman atau cache pelayar pada peranti yang menyimpan rekod asal.
- Simpan sandaran JSON penuh secara berkala. Sandaran penuh merangkumi lampiran evidens.
- Pakej ini menyediakan fail untuk dimuat naik; ia tidak mengubah repositori GitHub secara automatik.
