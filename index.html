Sandaran & Data

Pengurusan keselamatan data setempat.

Aplikasi ini local-first: tiada data dihantar ke pelayan dan tiada penyegerakan automatik antara peranti. Data boleh hilang jika data pelayar dipadam atau peranti rosak. Buat sandaran berkala.

Sandaran penuh

Termasuk profil, tetapan, semua modul, tong sampah dan lampiran.

Pulihkan sandaran

Tong sampah

Entri yang dipadam disimpan selama 30 hari sebelum dibuang terus bersama lampirannya.

Import rekod daripada CSV / Excel

Dari Excel: Fail → Simpan Sebagai → CSV UTF-8. Lajur dikenal pasti mengikut nama, contohnya Tarikh, Tajuk, Kategori, Penganjur, Jam, Peringkat. Tarikh boleh dalam format 31/12/2025 atau 2025-12-31.

Pasang sebagai aplikasi

Android / Chrome / Edge: tekan butang "Pasang Aplikasi" di bahagian atas, atau menu pelayar → Pasang aplikasi.
iPhone / iPad: buka dalam Safari → butang Kongsi → Tambah ke Skrin Utama.

Penting untuk iPhone/iPad: data dalam Safari dan dalam aplikasi di Skrin Utama disimpan berasingan. Jika anda sudah merekod dalam Safari: (1) buat sandaran JSON dalam Safari, (2) pasang aplikasi, (3) buka aplikasi dan pulihkan sandaran dengan pilihan "Gantikan semua data".
